# Afterglow ’84

> A restrained retro palette for the hour between sunlight and evening.

## Theme notes

- **Warm:** apricot functions and sage strings
- **Calm:** plum surfaces with low visual noise
- **Clear:** a deliberate syntax hierarchy

Try `npm run validate`, then open [the TypeScript preview](preview.ts).
